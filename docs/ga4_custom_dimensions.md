# GA4 Custom Dimensions Checklist

Register these GA4 event-scoped custom dimensions so RootFetch event params appear in reports:

- `tld`
- `sector`
- `cadence`
- `page_type`
- `range_days`
- `q_len`
- `hits_count`
- `status`

Also useful optional dimensions:

- `label`
- `href`
- `chart`
- `table`
- `sort_key`
- `direction`
