# Operations Scoreboard

RootFetch maintains an operations scoreboard artifact at:

- `data/ops/scoreboard_latest.json`
- public mirror: `/rootfetch/ops_scoreboard_latest.json`
- UI page: `/ops`

## Generator

The scoreboard is generated by:

```bash
python3 scripts/build_ops_scoreboard.py
```

`scripts/local_run_hybrid.sh` runs this automatically after publish.

## Inputs

- `data/artifacts/replay/index.json`
- `docs/briefs/*.md` (brief cadence counts)
- `data/ops/external_citations_log.csv`
- `data/ops/drill_log.csv`
- `data/ops/adoption_log.csv`

## Operator Logs

Use these append-only CSV logs:

- `data/ops/external_citations_log.csv`
- `data/ops/drill_log.csv`
- `data/ops/adoption_log.csv`

These logs are intentionally simple so updates can be audited in git history.
