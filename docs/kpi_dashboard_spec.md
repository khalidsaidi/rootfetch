# RootFetch KPI Dashboard Specification 2026

Status: Derived from `docs/strategy_2026.md`

All metrics map to defined phase goals.

## 1) Phase 1 — Structural Reference KPIs

Strategy reference: `strategy_2026.md` -> Phase 1

Primary:

- Number of runs archived
- Number of structural briefs published
- Number of structural updates published
- Replay index growth rate
- Run page views
- Compare page views

Secondary:

- SDK verification calls (if measurable)
- RSS feed pulls

## 2) Phase 2 — Integration Layer KPIs

Strategy reference: `strategy_2026.md` -> Phase 2

Primary:

- npm installs (JS SDK)
- pip installs (Python SDK)
- Example repo clones
- Webhook events processed

Secondary:

- Third-party integration mentions
- Verified badge usage

## 3) Phase 3 — Early-Warning Layer KPIs

Strategy reference: `strategy_2026.md` -> Phase 3

Primary:

- Regime bulletins issued
- Concentration bulletins issued
- Structural risk notes published
- External citations referencing run IDs or compare links

## 4) Explicit Non-KPIs

The following are not tracked as strategic indicators:

- Social follower count
- Engagement impressions
- Viral metrics
- Non-artifact-based mentions

## 5) Reporting Interval

- Monthly internal review
- Quarterly structural assessment

## 6) Final Rule

Every KPI must trace back to:

- Mission
- Phase goal
- Operating principle

If it cannot be traced, it does not belong.

- Canonical goals and terms: `docs/strategy_2026.md`
- Operational schedule context: `docs/cadence_calendar_2026.md`

This document defines measurement only.
