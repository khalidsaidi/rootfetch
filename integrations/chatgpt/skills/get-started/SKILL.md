# Get started with RootFetch

1. Ask the user which domain extension they're curious about, or a link they received. If they have none, suggest a popular one such as .xyz, .shop or .app.
2. Call `lookup_tld` with it. A full domain such as `shop.example.top` works too.
3. Report the number of registered domains, its rank, who runs it, its recent growth and the safety verdict, in plain words, with the link to its RootFetch page.
4. Offer two next steps: `compare_tlds` against similar extensions, or `recent_jumps` to see which extensions had sudden registration bursts lately.

Use only what the tools return. Explain that a safety verdict is about the extension as a whole, not any single website. If the extension is .com or a country code such as .uk, say RootFetch doesn't cover it.
